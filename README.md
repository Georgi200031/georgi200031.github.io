# Highway: Roadster — developer support

Static developer-support website for Highway: Roadster, with privacy information and app-ads.txt.

## Files

- index.html: support landing page.
- privacy.html: privacy policy.
- app-ads.txt: advertising-authorisation declaration.

There is no package installation or build step. Preview index.html directly or serve the directory with a static server. The repository name is the GitHub Pages user-site convention.

Preserve the privacy URL and the exact app-ads.txt declaration unless the app's real provider settings change. This repository is a support site, not the game's source code.

## Maintenance

Preserve the existing source and sample assets when making changes. Do not commit credentials, personal data or generated build output. This review documents the checked-in project; it does not certify production readiness or a successful build on every platform.
